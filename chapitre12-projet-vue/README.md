# Chapitre 12 (partie 2) — Pratiques Vue.js

Projet Vue.js complet contenant toutes les pratiques et l'exercice du chapitre.

## Comment lancer le projet

1. Ouvrir un terminal dans ce dossier
2. Installer les dépendances :
   npm install
3. Lancer le serveur de développement :
   npm run dev
4. Ouvrir l'adresse affichée dans le terminal (ex: http://localhost:5173) dans le navigateur

## Contenu

- Pratique 1 : Template Refs (button + $refs)
- Exercice : copier le texte de p1 vers p2 avec $refs
- Pratique 2 : Hook "created"
- Pratique 3 : Hook "mounted" (change la couleur de fond)
- Pratique 4 : Hook "updated"
- Pratique 5 : Hook "unmounted" (alerte)
- Pratique 6 : Provide / Inject (liste de fruits)

Chaque pratique est un composant séparé dans src/components/,
et tout est rassemblé dans src/App.vue.

Ouvrir la console du navigateur (F12) pour voir les console.log()
des Pratiques 2 et 4.
